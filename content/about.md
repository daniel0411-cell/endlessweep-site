## What Endlessweep provides

Endlessweep is an independent browser game and learning site for Minesweeper. It combines classic boards with No-Guess, Daily, Endless, Zen, practice, replay, and mistake-review tools. The site is designed to work without an account or download, with progress and records stored locally in the current browser.

## How we approach game content

Our guides explain rules, controls, number patterns, first-click behavior, probability limits, and common mistakes. Interactive claims are checked against the game implementation and regression tests before release. When a feature changes, the related guide and mode description should be updated with it.

## Independent project

Endlessweep is an independent project and is not affiliated with Microsoft or any other Minesweeper publisher. Product names and historical references belong to their respective owners.
