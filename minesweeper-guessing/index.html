Minesweeper Guessing and Probability

Make sure the board is truly uncertain before you take a risk.

Do you always have to guess in Minesweeper?

No. Many positions that look uncertain still contain a logical move. Before guessing, check every open boundary, subtract known flags from each clue, and compare overlapping groups of covered squares. A move is forced when only one mine arrangement satisfies all visible clues.

Important: A standard randomly generated board can contain a genuinely ambiguous position. Endlessweep protects the first click, but it does not label ordinary games as guaranteed no-guess boards.

Logic first: the pre-guess checklist

  1. Check whether a number already touches its full count of flagged mines. Its other covered neighbors are safe.
  2. Check whether a number needs exactly as many mines as it has unflagged covered neighbors. Those neighbors are mines.
  3. Compare nearby clues as sets. One clue may contain all the candidates of another plus one extra square.
  4. Look elsewhere on the board. A different boundary may provide new information before you return.
  5. Recheck every flag. A wrong flag can create a false dead end.

What is a 50/50 in Minesweeper?

A true 50/50 has two covered candidates, exactly one remaining mine among them, and no other clue that distinguishes the candidates. Both mine placements satisfy every visible number, so each square has the same risk.

Pattern recognition cannot solve a true 50/50. If another unopened region exists, solve it first. Otherwise, either choice is equally supported by the visible information.

Use global mine count to compare risks

The remaining mine counter can separate two regions that look locally uncertain. Suppose one group has one mine among two squares while another has one mine among four squares. Without additional constraints, each square in the first group carries more risk than each square in the second.

This is a comparison, not a guarantee. Shared clues and overlapping candidate groups change the calculation, so count complete valid arrangements rather than treating every covered square as independent.

Edges, corners and opening information

Edges and corners have fewer neighbors, which often makes their constraints easier to read. That does not automatically make every corner click safer. Prefer a move supported by visible clues; when no clues distinguish choices, choose the region with the lower estimated mine density.

What is No-Guess Minesweeper?

No-guess mode uses boards that can be completed through deduction from the protected opening. A correct implementation must generate or verify a full logical solution path. Simply moving a mine after a risky click is not the same thing, and an ordinary random board should not be advertised as no-guess without that verification.

Learn from a bad guess

After a loss on Endlessweep, use Review mistake to return to the position immediately before the mine was opened. Check whether another boundary or number pattern offered a certain move. If none did, compare the available risks instead of judging the result alone.
